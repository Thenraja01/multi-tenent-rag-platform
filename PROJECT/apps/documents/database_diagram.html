🗄️ Detailed Table Schema Specifications

11 Database Tables Registered

tenants

Platform Core

Stores platform organization accounts, SuperAdmin approval lifecycle status, and assigned subdomains.

ColumnTypeConstraint
idVARCHARPK (UUID)
nameVARCHAR(100)NOT NULL
subdomainVARCHAR(50)UNIQUE, INDEX (Assigned by SuperAdmin)
org_emailVARCHAR(255)NOT NULL
admin_nameVARCHAR(100)NOT NULL
admin_emailVARCHAR(255)NOT NULL
statusVARCHAR(20)INDEX (pending, approved, suspended, rejected)
approved_atTIMESTAMPNULLABLE
approved_byVARCHARNULLABLE

departments

Tenant Department

Stores department workspaces (HR, Tech, Finance) within an organization. `(tenant_id, slug)` is unique.

ColumnTypeConstraint
idVARCHARPK (UUID)
tenant_idVARCHARFK (tenants.id), INDEX
nameVARCHAR(100)NOT NULL
slugVARCHAR(50)UNIQUE(tenant_id, slug), INDEX
descriptionVARCHAR(255)NULLABLE
statusVARCHAR(20)DEFAULT 'active'

users

Identity Model

Stores user accounts. `tenant_id` is NULL for platform SuperAdmin users, or FK for organization members.

ColumnTypeConstraint
idVARCHARPK (UUID)
tenant_idVARCHARFK (tenants.id), NULLABLE (SuperAdmin)
emailVARCHAR(120)UNIQUE, INDEX
full_nameVARCHAR(100)NOT NULL
password_hashVARCHAR(255)NULLABLE
roleVARCHAR(50)SUPER_ADMIN, org_admin, member

roles

Dynamic RBAC

Database-driven roles with granular permission arrays. `department_id` is NULL for tenant-wide roles.

ColumnTypeConstraint
idVARCHARPK (UUID)
tenant_idVARCHARFK (tenants.id), INDEX
department_idVARCHARFK (departments.id), NULLABLE (Tenant-wide)
nameVARCHAR(100)e.g. ORG_ADMIN, HR_RECRUITER, TECH_DEV
permissionsJSONArray of permission keys e.g. ["documents.read"]

documents

Knowledge Assets

Physical document registry with visibility tags (`public`, `department`, `role_restricted`).

ColumnTypeConstraint
idVARCHARPK (UUID)
tenant_idVARCHARFK (tenants.id), INDEX
filenameVARCHAR(255)NOT NULL
visibilityVARCHAR(30)INDEX (public, department, role_restricted)
file_pathVARCHAR(512)NULLABLE

document_chunks

pgvector Storage

Vector embedding storage (1536d) with security metadata for similarity retrieval.

ColumnTypeConstraint
idVARCHARPK (UUID)
document_idVARCHARFK (documents.id), INDEX
tenant_idVARCHARINDEX (Hard RLS boundary)
domain_idVARCHARINDEX (Department slug/ID)
embeddingVECTOR(1536)Cosine similarity index
allowed_rolesJSONArray of allowed role names/IDs
