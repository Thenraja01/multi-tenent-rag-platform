# Project Overview

The Multi-Tenant Domain-Based Enterprise RAG Platform is a B2B SaaS product that delivers secure, AI powered knowledge management across independent business departments for multiple companies simultaneously.

## Quick Start

### Start API Backend:
```bash
cd PROJECT/apps/api
venv\Scripts\activate
python main.py
```

### Start Web Frontend:
```bash
cd PROJECT/apps/nexus
npm run dev
```
